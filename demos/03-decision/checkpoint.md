# MARIS flow checkpoint — an explicit human decision, not automatic monitoring

**When triggered:** an *in-session* agent has assembled evidence and is about to commit effort to a specific first prototype. It does not claim to monitor another agent in the background.

**Decision:** Choose the first open-source engineering software interoperability demonstrator.

**Evidence:** FMI, FreeCAD/STEP, OpenROAD/RTL-to-GDS are established open ecosystems (`evidence/source-ledger.json`, IDs FMI-01, CAD-01, EDA-01). Effort, performance, market demand and legal rights are still unverified.

**Profile effect:** if the **fictional** project profile prioritizes PDE-based validation and eight-week execution, prioritize the FMI/SSP trial. If the team instead has an actual ASIC workflow customer and EDA expertise, the EDA pilot may be better.

**Human gate (choose one):**
- A. Confirm dynamic-model interoperability as the pilot user → draft a small FMI benchmark plan.
- B. Confirm digital ASIC/EDA adopter → switch to OpenROAD flow-audit plan.
- C. Confirm CAD geometry adopter → specify a STEP round-trip pilot.
- D. No selection → gather three user interviews and technical install evidence first.

**Non-goals:** reverse-engineer unlicensed proprietary file contents, access confidential model assets, claim full-equivalence, silently initiate engineering work.
